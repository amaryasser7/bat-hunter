The game is a 3D shooter game. You should kill the bats, for each bat, the score 
increase by one 

-----------------------------------------------------------------------------------

**Controllers:**
- w --> move forward
- a --> move left
- d --> move right 
- s --> move backwards
  
  <br>
- up --> move forward
- down --> move backwards
- right --> move right
- left --> move left
  
  <br>
- space --> jump 
- Right mouse click --> shoot fireball
